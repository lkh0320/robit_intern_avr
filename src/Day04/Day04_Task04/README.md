# 1. 개요 (Overview)

본 과제는 ATmega128의 ADC와 Timer1 인터럽트를 이용하여 PSD 거리센서의 거리를 일정한 주기로 측정하고, 가중 이동 평균(Weighted Moving Average, WMA) 필터를 적용하여 노이즈를 감소시킨 후 UART를 통해 PC로 출력하는 프로그램을 구현하는 것을 목표로 한다.

PSD 센서는 주변 조명이나 센서의 미세한 흔들림에 의해 순간적인 노이즈가 발생할 수 있기 때문에, 최근 측정값에 더 높은 가중치를 부여하는 WMA 필터를 적용하여 보다 안정적인 거리 측정이 가능하도록 구현하였다.

또한 Timer1 Compare Match 인터럽트를 이용하여 일정한 시간마다 측정을 수행하도록 구성하고, 인터럽트에서는 플래그만 설정하여 실제 측정과 출력은 메인 루프에서 처리하도록 설계하였다.

# 5. main.c 구현

## 측정 주기 설정

프로그램은 Timer1 Compare Match 인터럽트를 이용하여 일정한 간격으로 PSD 센서를 측정한다.

```c
#define MEASURE_INTERVAL_MS 200UL
```

측정 주기를 매크로로 정의하여 프로그램 수정 없이 손쉽게 측정 주기를 변경할 수 있도록 하였다.

---

## Timer1 초기화

Timer1은 CTC(Clear Timer on Compare Match) 모드로 설정하였다.

```c
TCCR1A = 0x00;

TCCR1B =
    (1 << WGM12) |
    (1 << CS12) |
    (1 << CS10);
```

CTC 모드를 사용하면 OCR1A 값에 도달할 때마다 자동으로 카운터가 초기화되므로 일정한 주기의 인터럽트를 생성할 수 있다.

이후 계산된 OCR1A 값을 적용하고 Compare Match 인터럽트를 허용하였다.

```c
OCR1A = OCR1A_VALUE;

TIMSK |= (1 << OCIE1A);
```

---

## Timer1 인터럽트

인터럽트에서는 ADC 측정이나 UART 출력과 같은 시간이 오래 걸리는 작업을 수행하지 않고 측정 플래그만 변경한다.

```c
ISR(TIMER1_COMPA_vect)
{
    measure_flag = 1;
}
```

실제 센서 측정은 메인 루프에서 수행하여 인터럽트 처리 시간을 최소화하였다.

---

## 가중 이동 평균(WMA) 필터

PSD 센서는 순간적인 노이즈가 발생할 수 있기 때문에 최근 측정값 5개를 이용한 가중 이동 평균 필터를 적용하였다.

가중치는 다음과 같이 설정하였다.

```text
1 : 2 : 3 : 4 : 5
```

가장 최근에 측정한 데이터일수록 높은 가중치를 부여하여 단순 평균보다 센서 변화에 빠르게 반응하도록 구현하였다.

필터 처리 과정은 다음과 같다.

```text
새로운 ADC 측정

↓

기존 데이터 한 칸 이동

↓

최신 데이터 저장

↓

가중 평균 계산

↓

필터링된 ADC 값 반환
```

초기에는 배열이 모두 채워지지 않았기 때문에 실제 저장된 데이터 개수(`window_count`)를 이용하여 의미 없는 0값이 평균 계산에 포함되지 않도록 구현하였다.

---

## 거리 계산

필터링된 ADC 값을 이용하여 실제 거리(cm)를 계산하였다.

```c
distance =
A / (ADC + B)
- C
```

PSD 센서는 출력 특성이 선형이 아니므로 실측 데이터를 기반으로 한 보정식을 적용하였다.

거리는 소수점 첫째 자리까지 출력하기 위해 실제 거리값에 10을 곱한 정수 형태로 저장하였다.

예를 들어

```text
25.3 cm

↓

253
```

으로 저장하여 float 출력 없이도 소수점을 표현할 수 있도록 구현하였다.

---

## 측정값 검증

측정된 데이터의 신뢰성을 높이기 위해 두 가지 조건을 검사하였다.

* ADC 값이 정상 범위인지 확인
* 계산된 거리가 센서 측정 범위인지 확인

범위를 벗어난 경우에는 정상 데이터로 처리하지 않고 오류 메시지를 출력하도록 구현하였다.

---

## 거리 측정 함수

센서 측정 과정은 `Measure_And_Print()` 함수에서 수행한다.

동작 순서는 다음과 같다.

```text
ADC 측정

↓

가중 이동 평균 적용

↓

거리 계산

↓

RAW 값 출력

↓

FILTERED 값 출력

↓

거리 출력 또는 오류 출력
```

거리 계산에는 필터링된 ADC 값을 사용하여 안정적인 측정 결과를 얻도록 하였으며, 센서 이상 여부는 RAW ADC 값을 기준으로 판단하여 순간적인 이상 신호도 확인할 수 있도록 구현하였다.

---

## main 함수

메인 함수에서는 시스템에 필요한 주변장치를 초기화한 후 무한 루프를 실행한다.

초기화 순서는 다음과 같다.

```text
ADC 초기화

↓

UART0 초기화

↓

Timer1 초기화

↓

전역 인터럽트 허용

↓

시작 메시지 출력
```

이후 무한 루프에서는 Timer1 인터럽트에서 설정한 `measure_flag`를 확인하여 측정 요청이 발생한 경우에만 센서를 측정하고 UART로 출력한다.

```text
measure_flag 검사

↓

센서 측정

↓

필터 적용

↓

거리 계산

↓

UART 출력

↓

반복
```

이와 같은 구조를 사용하여 인터럽트는 매우 짧게 실행되고 실제 데이터 처리는 메인 루프에서 수행하도록 구현하였다.

# 6. ADC 모듈

ADC 모듈은 PSD 센서의 아날로그 출력 전압을 디지털 값으로 변환하는 기능을 수행한다.

주요 기능은 다음과 같다.

* ADC 초기화
* ADC 채널 선택
* 변환 시작
* 변환 완료 대기
* ADC 데이터 반환

---

# 7. UART 모듈

UART 모듈은 측정된 데이터를 PC의 시리얼 모니터로 전송하는 기능을 수행한다.

주요 기능은 다음과 같다.

* UART 초기화
* 문자열 출력
* 정수 출력
* 소수점 한 자리 출력
* 줄바꿈 출력

통신 속도는 9600bps로 설정하였다.

